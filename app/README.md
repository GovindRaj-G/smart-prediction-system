# Smart Prediction System

## Project Overview

Smart Prediction System is a Machine Learning application that predicts Iris flower species based on four input measurements.

The application uses a trained classification model and an interactive Streamlit interface to generate predictions.

## Objectives

- Build a Machine Learning classification model.
- Prepare and analyze a dataset.
- Train and evaluate the model.
- Predict flower species using new measurements.
- Build a web interface using Streamlit.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Joblib

## Dataset

The Iris dataset contains flower measurements:

- Sepal length
- Sepal width
- Petal length
- Petal width

The model predicts one of three species:

- Setosa
- Versicolor
- Virginica

## Project Workflow

1. Dataset creation
2. Exploratory Data Analysis
3. Data preprocessing
4. Training and testing data split
5. Machine Learning model training
6. Model evaluation
7. Prediction system development
8. Streamlit web application

## Machine Learning Algorithm

The project uses the K-Nearest Neighbors (KNN) classification algorithm with feature scaling.

## Application Features

- Interactive measurement inputs
- Flower species prediction
- Prediction probabilities
- Model accuracy
- Confusion matrix
- Classification report
- Data visualization

## How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd Smart_Prediction_System
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```
